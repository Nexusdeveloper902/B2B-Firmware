## Discoveries

- OBS-001: ArduinoJson 7's `| nullptr` fallback form silently returns
  null even for present keys — direct implicit conversion is the correct
  read. Found via host tests; locked by regression tests.
- PlatformIO registry truth: the RC522 library is registered as
  `miguelbalboa/MFRC522` (max registry version 1.4.12, not the GitHub
  1.6.x tags); its API uses `MFRC522::PCD_Register::VersionReg`.
- PlatformIO native testing links ALL test/*.cpp into ONE program → one
  main() + shared setUp/tearDown (test_main.cpp pattern), else
  multiple-definition link errors.
- Sandbox process reaping kills detached background jobs; long builds/
  servers must run in foreground (or be re-driven per step).
