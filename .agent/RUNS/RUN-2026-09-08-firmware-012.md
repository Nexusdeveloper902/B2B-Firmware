idle patterns OFF-dominant, and documents all three modes bilingually.

## Notes for the bench
- A board that still shows a SOLID white LED is running a pre-e75e190
  build or has the RST wire still on GPIO4 — move it to 3V3 and
  reflash; the new asserts forbid GPIO4 in any driven role.
- A board that shows a SOLID red LED on a genuine current station
  build is an inverted-polarity clone → flip
  `PIN_STATION_LED_ACTIVE_LOW` to 0 and rebuild.
- Short blips are the station TALKING (1=operation, 2=pairing,
  3=degraded) — not a fault.
