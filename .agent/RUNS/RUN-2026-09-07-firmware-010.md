## Discoveries
1. B2B-Core TASK-025 (landed the same date) changed the optimal camera
   wiring: the bottle-first capture endpoint needs NO event_id, so a
   standalone camera station is complete without learning anything
   about taps. TASK-008's original text predates that endpoint.
2. The reference's 'c' command stays useful (local capture for the
   visualizer) and coexists cleanly with the new ENTER flow.
3. Arduino envs compile C++11: structs with default member initializers
   are not aggregates there — brace-init fails on device but succeeds
   on the native env's newer standard. Explicit constructors keep every
   env on the same code (a trap worth remembering for future structs).
