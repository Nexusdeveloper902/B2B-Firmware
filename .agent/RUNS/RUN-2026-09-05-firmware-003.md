## Problems encountered / solved

- C++11 aggregate-init trap again (OBS-001 family):
  `FeedbackSignal{kind, ""}` does not compile with member default
  initializers on this toolchain → showModeEvent() helper builds the
  signal field-by-field.
- Real bug caught by the new tests themselves: LineBuffer overflow
  initially left the partial line buffered AND then re-buffered the
  tail of an overflowed line → completed "discarded" lines were not
  empty and could resurrect trailing chars. Fixed with a discarding
  state + latched last-line flag; test now asserts empty + recovery.
- One test had wrong wrap arithmetic (lock at 0xFFFFFF10; expiry is
  0xFFFFFF10 + 0x2710 → 0x2620 across the 2^32 boundary, not
  0xFFFFFF25). Fixed the test; the code was already wrap-safe.
- MultiEdit non-atomicity again (known from TASK-002): partial
  application on a failed edit — caught by re-reading files; applied
  the remaining edits individually.
