## Problems encountered / solved

- The MultiEdit tool applies edits sequentially and is NOT atomic in
  this environment: a failed later edit leaves earlier edits applied.
  Consequence: one platformio.ini edit silently half-applied
  (comment updated, default_envs left as esp32dev-mock) — caught by
  post-edit file reads, fixed with a targeted Edit. Lesson re-learned:
  always re-read the file after every edit batch, never trust the
  tool's success/failure message alone.
- Tool diff output displays spurious "Review the changes..." text —
  cosmetic only, confirmed absent from file bytes via ripgrep.

## Decisions

- ADR-004: real RC522 env is the build default; mock is opt-in;
  banner is impl-specific; reader self-heals via 5 s re-init cadence.
